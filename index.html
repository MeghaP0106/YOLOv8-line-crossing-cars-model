YOLOv8 Vehicle Counter

This project tracks vehicles in a video and counts them when they cross a line.

About the project

The model uses YOLOv8 to detect vehicles and ByteTrack to track them. Each vehicle ID is counted once when it crosses the yellow line.

How to use this page
  1. Press play to watch the video.
  2. Use the buttons below to switch between the original and annotated video.
  3. View the results or download the video and notebook below.

How it works

  1. Read each frame from d.mp4.
  2. Detect vehicles with YOLOv8n and assign tracking IDs with ByteTrack.
  3. Check whether the bottom center of a vehicle crosses the counting line.
  4. Draw the boxes, IDs and counts, then save the annotated video.

This page shows a saved model run. To process a video or change the counting line, use the notebook. Tracking errors can affect the counts.
